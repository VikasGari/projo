# Projo - Collaborative Project Management Platform

Projo is a comprehensive project management platform that enables teams to collaborate effectively on projects, manage tasks, communicate, and stay organized. Built with modern web technologies, it provides a seamless experience for team collaboration and project management.

## 🌟 Features

### Team Management
- Create and manage teams with customizable roles
- Team member invitations and join requests
- Team chat functionality
- Team activity tracking

### Project Management
- Kanban-style task board
- Task assignment and tracking
- Project status monitoring
- Deadline management
- Project chat and collaboration

### Task Management
- Drag-and-drop task organization
- Task assignment and reassignment
- Priority levels and due dates
- Task comments and remarks
- Task status tracking

### Notes
- Markdown support for rich text
- Auto-save functionality
- Note organization and search
- Tag support for better organization

### Events & Calendar
- Calendar view for event management
- Event creation and editing
- Event categories and tags
- Event reminders
- Event sharing capabilities

### Contacts
- Contact management system
- Contact sharing
- Multiple contact views (list/grid)
- Contact categorization

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router for navigation
- Context API for state management
- Material-UI for components
- Socket.io for real-time features
- Markdown-it for rich text

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT for authentication
- Socket.io for real-time communication
- Bcrypt for password hashing

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/VikasGari/projo.git
cd projo
```

2. Install frontend dependencies:
```bash
cd frontend
npm install
```

3. Install backend dependencies:
```bash
cd ../backend
npm install
```

4. Set up environment variables:
Create `.env` files in both frontend and backend directories with necessary configurations.

5. Start the development servers:

Frontend:
```bash
cd frontend
npm start
```

Backend:
```bash
cd backend
npm start
```
